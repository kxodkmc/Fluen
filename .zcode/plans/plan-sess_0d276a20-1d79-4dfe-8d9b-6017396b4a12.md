## 目标

在 Motis 聊天面板实现「上下文容量」系统：进度条显示 `已用/窗口 (百分比)`，并按分类拆解占比（消息 / 系统提示词 / 工具定义 / 子智能体清单 / 成果板 / 输出预留），同时展示 API 返回的真实 prompt_tokens。**不修改 `crates/referee` 子仓库**——全部逻辑在 src-tauri 应用层完成，复用 `referee_ai::budget::TokenEstimator`（已是公开 API）。

## 后端（Rust，src-tauri）

1. **新模块 `src-tauri/src/motis_chat/context_usage.rs`**
   - `ContextUsageReport { categories: Vec<ContextCategory{key, tokens}>, estimated_prompt_tokens, context_window, max_output_tokens }`（serde camelCase，供前端直接消费）。
   - `build_report(...)`：用 `TokenEstimator::estimate` 估算各分类——
     - `messages`：history 消息 + 本轮用户输入
     - `system_prompt`：基础提示词各段
     - `sub_agents` / `board`：子智能体清单段、成果板段（从系统提示词中拆出）
     - `tools`：`ToolDeclaration` 的 name + description + parameters JSON 序列化后估算
     - `output_reserved`：`max_output_tokens`
   - 附单元测试。

2. **`motis_chat/prompt.rs`**：新增 `build_system_prompt_parts()` 返回带类别标签的段落列表；现有 `build_system_prompt()` 改为 join 包装，行为不变（commands.rs 与既有测试不受影响）。

3. **`motis_chat/runtime.rs`**：`build_runtime` 返回值增加工具清单——`build_motis_tool_registry` 后调用 `registry.declarations()` 一并返回（工具不可用时为空 Vec）。

4. **`llm_chat.rs`**：把 `resolve_model_spec` 暴露为 pub（或加一个 pub 包装），供 commands 层取 `(context_window, max_output)`，回退逻辑不变（128K/16K）。

5. **`motis_chat/events.rs`**：新增事件名 `motis:context-usage` 与 `ContextUsagePayload`；`FinishPayload` 扩展 `prompt_tokens: Option<usize>`、`completion_tokens: Option<usize>`。

6. **`chat_bridge.rs`**：`consume_stream` 的 `last_usage` 从 `Option<usize>`（仅 total）改为保留完整 `TokenUsage`，finish 事件带上真实 prompt/completion（vendor 不上报时为 None，现有取消/错误路径逻辑不变）。

7. **`motis_chat/commands.rs`**：`motis_chat_send` 在 `start_chat_session` 前用当轮的 system prompt 分段、工具声明、history、message、模型规格构建报告并 `emit("motis:context-usage")`——每轮发送即刷新一次面板。

## 前端（Vue 3）

8. **`views/main/composables/useMotisChat.ts`**：新增 `contextUsage` ref；`subscribeEvents()` 增订 `motis:context-usage`；`onFinish` 不再丢弃负载，存下真实 usage；通过 `MOTIS_CHAT_KEY` 接口暴露。类型定义放 `views/main/types.ts`。

9. **新组件 `components/motis/MotisContextUsage.vue`**：
   - 收起态：头部小按钮显示百分比（如 `12.5%`）；
   - 展开态：下拉面板（沿用 ChatInputToolbar 的绝对定位 + 外部点击关闭模式、`--fluen-*` 设计令牌）——顶部进度条 `已用/窗口 (百分比)`，下方分类行（占比 = 分类 tokens / 估算 prompt 总量，为 0 的类别隐藏），有真实 usage 时显示「实际用量」行；
   - 挂载到 `MotisChatHeader.vue`（关闭按钮左侧）。

10. **i18n**：`main.contextUsage.*` 词条补进 `zh-CN.ts` / `en.ts` / `es.ts` 及 `i18n/types.ts` 的 MessageSchema。

## 验证

- `cargo test -p`（src-tauri 包名）跑新增单测 + 既有 prompt/chat_bridge 测试；`cargo check` 确认无回归。
- 前端 `pnpm vue-tsc`/`pnpm build` 通过。
- 说明：估算基于 ~1.5 字符/token 的启发式（与引擎截断同源），真实 prompt_tokens 依赖 vendor 是否上报，面板上两者并列展示、口径在 UI 文案中说明。
