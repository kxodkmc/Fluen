# 修订计划 v2 — 以 referee 联邦拓扑为核心的收尾方案

## 设计修正说明（回应三个质疑）
上一版 WP2 的手搓 `HashMap` 运行时池**废弃**。探查证实了关键事实：`AgentRuntime::handle` 把信封中的 `session_id` 原样转发给 `engine.chat()`（lib.rs:299-302），协议层天然支持任意新会话——「固定目标会话」只是 `AgentTool` 构造函数的封装选择，不是协议约束。因此：

- **模块化**：新增 `motis_chat/federation.rs` 单一模块承载联邦装配；委派工具退化为 ~100 行的 referee 原语组合（kernel.invoke + SessionMessage 协议），无平行发明的生命周期设施。
- **referee 哲学**：遵循交接文档约定第 2 条「原语下沉 referee」——编排用 Kernel 能力路由、子代理宿主用 AgentRuntime 扩展、大结果用 ArtifactStore ACL，Fluen 只做门面/审批桥接。
- **用好特性**：CapabilityId 路由、Extension 拓扑、按调用者分板的工件 ACL（>4096 字节自动落库防上下文爆炸）、声明式 `depth_limited()` 门控 + 引擎 `max_subagent_depth` 兜底、`session_consumed_tokens` 观测。
- **硬约束**：全程只调 referee 公开 API，不改 referee/socstat 任何源码。

## WP2 — Motis 联邦化（核心改造，src-tauri，不动 referee）
新建 `motis_chat/federation.rs`，波及 `delegate.rs`、`runtime.rs`、`commands.rs`、`agents.rs`：
1. **Federation 结构**：持有 `Kernel` + `HashMap<AgentId, (CapabilityId, AgentRuntime)>` + 指纹（agent × provider/model × project_path）+ 共享 `Arc<InMemoryArtifactStore>`。挂 `MotisChatState` 新字段惰性构建，指纹不符整体重建（子代理引擎从「每次委派重建」变「每指纹长寿命」，复用成为拓扑自然结果而非外挂缓存）。
2. **构建**：复用现有 `build_agent_runtime` 的工具集/提示词逻辑产出 Engine → `AgentRuntime::new(engine).with_artifact_store(store)` → `kernel.register()` 记录 CapabilityId。
3. **delegate_agent 重写为薄组合**：schema 保持 agent_id/task/wait 兼容；execute 铸造 `SessionId::new_v4()`（保留隔离语义）→ `SessionMessage::Chat { peer_depth: ctx.peer_depth + 1 }` → `kernel.invoke(runtime_id, …)`（超时可配，默认放宽至 600s，referee 默认 30s 不够论文写作）→ 解析 `SessionReply::Success`。工件策略照搬 referee：非等待或结果 >4096 字节 → `ensure_board(ctx.session_id)` 落库仅回 `{"artifact_id"}`。`category=Local`、`depth_limited=true`、`default_wait=true` 维持现状。
4. **注入**：Motis 引擎 `approval_executor().with_kernel(kernel.clone())`（builder 零改动）；tokens_used 经 `session_consumed_tokens` 快照差值计算保留输出形状。
5. **读取闭环**：Motis 注册 `ListMyBoard` + `ArtifactReader`（`register_artifact_tools`），落板正文模型可自主取回。
6. **取消传播**：Federation 跟踪活跃子会话，接入现有取消路径 `interrupt(child)`，修复 cancel_all 零调用点的泄漏。
7. **测试补齐**：delegate.rs 当前零测试（最高风险区）——为新工具补参数解析 / enabled_agents 过滤 / payload 形状 / artifact 阈值分支用例；Federation 构建 / 指纹失效用例。
8. ai_assistant 与 knowledge_builder 确认为叶子运行时（无委派），本轮不动。
